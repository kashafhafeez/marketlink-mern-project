# MarketLink – Project 

## 1. Project Title

**MarketLink**

**Theme:** eGreen Basket

**Project Type:** End-to-End Web Solution

---

## 2. Project Description

MarketLink is a full-stack web application developed as a student project to connect local farmers-market Farmers with customers.

The application allows customers to browse Farmers and products, search and filter products, view market locations, place pre-orders for pickup, manage their orders, save favorite products/Farmers, and provide reviews and ratings.

Farmers can manage their profiles, products, stock, prices, pickup information, and customer orders.

An Admin role is included for managing users, markets, content, reports, and other system-level information.

---

## 3. Technologies Used

The project is developed using the MERN stack:

* MongoDB – Database
* Express.js – Backend/API
* React.js – Frontend
* Node.js – Server-side runtime
* tailwind / CSS – Responsive UI, where used
* Google Maps API or OpenStreetMap – Map/location functionality, where implemented

---

## 4. Main User Roles

### Customer

Customers can:

* Register and login
* Browse markets and Farmers
* Search and filter products
* View product details
* View Farmer information
* Place pre-orders
* Manage orders
* View order history
* Save favorites
* Give reviews and ratings

### Farmer

Farmers can:

* Register and login
* Manage Farmer profile
* Add products
* Edit products
* Delete products
* Manage stock and prices
* View customer orders
* Accept or decline orders
* Manage pickup information
* View order history

### Admin

Admin can:

* Login to the Admin dashboard
* Manage Customers
* Manage Farmers
* Manage markets
* Manage product categories
* Moderate content
* View reports and platform information

---

## 5. Project Assumptions

The following assumptions were made during development:

1. The application is developed as a student academic project.
2. Payment gateway functionality is not included.
3. Customers pay for their orders physically at the pickup location.
4. Delivery/courier functionality is not included.
5. Orders are collected from the selected market/pickup location.
6. Farmer identity, licensing, organic certification, and food-safety certification are outside the application's functionality.
7. The map functionality depends on the selected map service and its available API/configuration.
8. Test accounts may be used for demonstrating Customer, Farmer, and Admin functionality.
9. Some advanced features may depend on the final project implementation and available third-party services.
10. The application is designed according to the requirements provided in the MarketLink SRS.
